# Классификация текстов фанфиков

Классификация русскоязычных фанфиков по жанрам **«Ангст»** и **«Юмор»** с использованием машинного обучения.

В проекте сравниваются способы представления текста — BoW, TF-IDF, Word2Vec и доли частей речи — и проверяется влияние фильтрации редких слов на качество классификации.

## Данные

Для классификации отобраны **616 работ** по вселенной Гарри Поттера, имеющих ровно одну из двух жанровых меток:

- **0 — Ангст**;
- **1 — Юмор**.

Используются сохранённые начала первых глав объёмом до 500 слов. Обучающая выборка содержит **491 работу**, тестовая — **125 работ**.

Разбиение выполнено **по авторам**: произведения одного автора не попадают одновременно в обучение и тест. В качестве признаков используются тексты, а жанровые теги служат целевой переменной.

## Предобработка и представление текста

Предобработка включает токенизацию, приведение к нижнему регистру, удаление пунктуации и стоп-слов, стемминг и лемматизацию. Для имён и терминов вселенной Гарри Поттера используются исключения.

Сравниваются следующие представления:

| Представление | Описание |
| --- | --- |
| Bag of Words — BoW | Частоты токенов в документе |
| TF-IDF | Частоты токенов с учётом их редкости в обучающем корпусе |
| Word2Vec | Средний вектор известных слов документа |
| Части речи | Доли грамматических категорий по spaCy, Natasha и pymorphy3 |

Для Word2Vec проверяются варианты без стемминга, со стеммингом и с лемматизацией. Используется Skip-gram: размер вектора 100, окно 5, `min_count=2`, 20 эпох. Word2Vec обучается только на обучающих текстах.

## Модели классификации

В работе применены три классификатора:

| Модель | Реализация | Настройки в итоговом сравнении |
| --- | --- | --- |
| Логистическая регрессия | `LogisticRegression` | `C=1`, `class_weight="balanced"`, `max_iter=2000` |
| Линейный метод опорных векторов | `LinearSVC` | `C=1`, `class_weight="balanced"` |
| Случайный лес | `RandomForestClassifier` | 100 деревьев, `min_samples_leaf=2`, `class_weight="balanced"` |

Для воспроизводимости задан `random_state=42`. Перед обучением линейных моделей плотные признаки Word2Vec и частей речи масштабируются по обучающей выборке.

## Эксперимент с фильтрацией редких слов

В исходном BoW не был указан нижний порог документной частоты, поэтому использовалось значение **`min_df=1`**.

Параметр `min_df` определяет минимальное число документов, в которых должен встретиться токен. Например, при `min_df=3` слово сохраняется только при наличии минимум в трёх обучающих документах, независимо от числа повторений внутри одного текста.

Проверены пороги **1, 2, 3, 5 и 10** на пяти внутренних разбиениях обучающей выборки по авторам. На каждом разбиении словарь строится заново только по внутреннему train. Критерий выбора — средний Macro-F1 на внутренней проверке.

Следующие результаты **пересчитаны заново**:

| Модель | Лучший порог среди ≥2 | Словарь: до → после | Macro-F1 теста: до → после | Лучший порог по CV, включая 1 |
| --- | --- | --- | --- | --- |
| Логистическая регрессия | 2 | 17 342 → 9 617 | 0,6111 → 0,6449 | **1** |
| Линейный SVM | 3 | 17 342 → 6 854 | 0,6560 → 0,6859 | **1** |
| Случайный лес | 10 | 17 342 → 2 458 | 0,5967 → 0,5969 | **10** |

Для сравнения фильтрации отдельно выбран лучший порог среди значений ≥2. Однако при включении исходного варианта внутренняя проверка предпочла **`min_df=1` для линейных моделей** и **`min_df=10` для случайного леса**.

Фильтрация значительно сократила словарь, но **переобучение сохранилось**: Macro-F1 на обучении равен 1,0 во всех вариантах. На тесте Macro-F1 линейных моделей вырос, однако ROC-AUC после фильтрации снизился у всех трёх классификаторов. Поэтому уменьшение словаря нельзя считать доказательством устойчивого улучшения.

В этом эксперименте настройки классификаторов одинаковы для baseline и filtered; меняется только `min_df`. Предел итераций линейных моделей увеличен в обеих ветках для сходимости.
