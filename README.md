# Классификация текстов фанфиков

Автор: Кротова Ксения, РИС-24-1.

Классификация русскоязычных фанфиков по жанрам «Ангст» и «Юмор»: BoW, TF-IDF, Word2Vec и признаки частей речи.

Основная работа находится в [fanfic_text_classification.ipynb](fanfic_text_classification.ipynb). В раздел **1.4а** встроен выполненный эксперимент с порогами документной частоты `min_df`: код, таблицы, графики и выводы. Остальные разделы полностью заново не запускались, их старые выводы очищены.

## Результаты эксперимента

616 работ: 491 в обучении и 125 в тесте. Разбиение по авторам. Пороги 1, 2, 3, 5, 10 проверяются на пяти внутренних разбиениях только обучающей выборки. На каждом разбиении словарь строится заново по внутреннему train.

| Модель | Лучший порог среди ≥2 | Словарь: до → после | Macro-F1 теста: до → после | Лучший порог по CV, включая 1 |
| --- | --- | --- | --- | --- |
| Логистическая регрессия | 2 | 17 342 → 9 617 | 0,6111 → 0,6449 | 1 |
| Линейный SVM | 3 | 17 342 → 6 854 | 0,6560 → 0,6859 | 1 |
| Случайный лес | 10 | 17 342 → 2 458 | 0,5967 → 0,5969 | 10 |

Фильтрация уменьшила словарь, но **переобучение сохранилось**: Macro-F1 на обучении равен 1,0 во всех вариантах. CV предпочла исходный порог для линейных моделей. Рост тестового Macro-F1 не доказывает устойчивого улучшения; ROC-AUC после фильтрации снизился. Тест уже использовался в исходной работе, статистическая значимость различий не установлена.

Настройки моделей фиксированы как в итоговом сравнении исходного ноутбука, а не в первоначальном подборе раздела 1.3. В обеих ветках повышен предел итераций линейных моделей. Исходные исторические выводы содержали 17 343 признака, текущий запуск — 17 342; причина расхождения без версий прежней среды и контрольной суммы прежнего CSV не установлена. Сравнение baseline/filtered выполнено в одной текущей среде.

## Файлы и запуск

- `fanfic_text_classification.ipynb` — вся работа и эксперимент с порогами.
- `requirements.txt` — зависимости для ноутбука.
- `src/` — код предобработки и эксперимента, который вызывает раздел 1.4а. Эта папка нужна для запуска.
- `ficbook_all_collected_1900.csv` — локальный корпус рядом с ноутбуком; исключён из Git.

Откройте ноутбук из этой папки. Для Python 3.12 установите зависимости:

```bash
python -m pip install -r requirements.txt
```

Для полного исходного анализа дополнительно нужны модель spaCy и стоп-слова NLTK:

```bash
python -m spacy download ru_core_news_sm
python -m nltk.downloader stopwords
```

Раздел 1.4а можно запустить отдельно: его первая ячейка сама загружает CSV и строит исходное разбиение. Для него скачивание модели spaCy и стоп-слов NLTK не требуется. При повторном расчёте автоматически появится папка `reports/` с таблицами и графиками.

Тексты произведений не входят в Git: права принадлежат их правообладателям. Без локального CSV доступны сохранённые результаты эксперимента, но повторное обучение невозможно. После запуска остальных разделов очистите выводы с фрагментами произведений перед публикацией.
